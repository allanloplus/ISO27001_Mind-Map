# Allan 老師錄音清單

共 36 句。每一句錄成一個檔案，檔名用表格中的編號（例如 `01-1.m4a`、`05-3.m4a`）。阿拉蕾的台詞不用錄，影片會自動放在 Allan 的句子之間。

## 錄音方式

- **器材：** 手機內建錄音 App 即可（iPhone「語音備忘錄」、Android「錄音機」），格式 m4a、wav、mp3 都可以。
- **環境：** 安靜、回音少的小房間，有窗簾、衣櫃或沙發最好；關掉冷氣、風扇。
- **距離：** 手機距離嘴巴約 20–30 公分，放在桌上、不要拿在手上，避免摩擦聲；每次錄音的位置和音量盡量相同。
- **前後留白：** 按下錄音後停 1 秒再開口，唸完停 1 秒再按停止。前後的空白我會自動修掉。
- **唸錯：** 直接整句重錄、覆蓋同一個檔名即可，不用剪接。
- **語氣：** 用平常上課的語氣就好，速度不用刻意配合；影片每一段的長度會跟著你的錄音自動調整。
- **改台詞：** 可以照你的習慣調整用字。我會用語音辨識比對，把字幕改成你實際唸的內容，改動較大的我會先跟你確認。

## 交付方式

- **方式一（建議）：** 把所有檔案壓縮成一個 zip，直接附加在對話中傳給我。
- **方式二：** 上傳到 GitHub 的 `recordings/allan/` 資料夾（repo 頁面 → Add file → Upload files，分支選 `claude/quirky-goodall-qprgao`）。
- 可以分批給，例如先錄前 10 句讓我試做，確認效果後再錄其餘的。
